01 · System integration

Hardware configuration had to become explicit before control work was safe.

Electrical and mechanical foundation

The robot uses eight 20 kg servos for hip and thigh joints, four 35 kg servos for the knees, a PCA9685 servo driver, an MPU6050 IMU, and separate regulated logic and servo power rails from a 3S LiPo.

A short circuit and failed servo driver during development made staged validation essential. The repository now documents power-off inspection, controller-only checks, one-channel-at-a-time calibration, sensor validation, motion demonstrations, and stabilization tests.

Configuration drift removedThe project robot uses contiguous channels 0–11, while the upstream Nova SM3 reference uses a different map. The two code paths are now explicitly separated.

02 · Control architecture

From measured pitch to mirrored stance correction.

The active experimental scope is deliberately narrow: read pitch, compute a bounded correction, respect calibration offsets, and command the twelve leg servos safely.

03 · Iteration

Separate what worked from what changed next.

The repository distinguishes recorded hardware behavior from later code changes that have not yet been validated on the robot.

Pitch stabilization v1

Hardware-tested response

Produced a successful recorded pitch response. Known issues included delayed recovery after lowering the board, free hip joints, resting bias, and vibration-driven twitching.

Tested on hardware

Pitch stabilization v2

Targeted controller revision

Adds a startup baseline, exponential filtering, active hip hold, proportional-only correction, and integral-windup removal. It remains intentionally labeled experimental.

Not yet hardware-tested

04 · Validation

Real motion evidence, with the remaining limits stated.

The new repository video is the strongest current proof that the robot responded to changes in pitch. It is linked rather than auto-loaded so a 17.4 MB file does not slow every portfolio visit.

The next useful evidence is quantitative: board angle, raw and filtered pitch, commanded correction, recovery time, and oscillation. Those measurements would turn the visual demonstration into a defensible controller-performance result.
