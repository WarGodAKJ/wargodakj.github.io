01 · System integration

Hardware configuration and safe startup.

Electrical and mechanical setup

The robot uses eight 20 kg servos for the hip and thigh joints, four 35 kg servos for the knees, a PCA9685 servo driver, an MPU6050 IMU, and separate regulated logic and servo power rails from a 3S LiPo.

A short circuit and failed servo driver during development led to a staged test procedure: power-off inspection, controller-only checks, one-channel-at-a-time calibration, sensor validation, motion demonstrations, and stabilization tests.

Servo channel mappingThe project robot uses contiguous channels 0–11. The upstream Nova SM3 reference uses a different map, so the repository keeps the two code paths separate.

02 · Controller implementation

Pitch feedback and mirrored leg commands.

The hardware-tested v1 controller calculates pitch from the accelerometer, runs a bounded PID controller, and applies opposing corrections to the front and rear leg pairs.

04 · Hardware test

Recorded auto-balancing response.

The video shows the physical robot responding to changes in platform pitch with the v1 controller.

What the test shows

The controller changes the front and rear leg commands in response to measured pitch. The test also exposed delayed recovery, free hip joints, resting bias, and vibration-driven twitching.

The experimental v2 revision addresses those observations with a 50-sample level reference, an exponential filter with α = 0.15, active hip hold, and proportional-only control. That revision is not yet hardware-tested.
