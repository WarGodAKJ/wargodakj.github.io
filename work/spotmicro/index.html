01 · System integration

Hardware configuration and safe startup.

Electrical and mechanical setup

The robot uses eight 20 kg servos for the hip and thigh joints, four 35 kg servos for the knees, a PCA9685 servo driver, an MPU6050 IMU, and separate regulated logic and servo power rails from a 3S LiPo.

A short circuit and failed servo driver during development led to a staged test procedure: power-off inspection, controller-only checks, one-channel-at-a-time calibration, sensor validation, motion demonstrations, and stabilization tests.

Servo channel mappingThe project robot uses contiguous channels 0–11. The upstream Nova SM3 reference uses a different map, so the repository keeps the two code paths separate.

03 · Iteration

Tested v1 controller and experimental v2 revision.

The repository separates the controller shown in the hardware video from later code changes that have not yet been tested on the robot.

Produced the recorded pitch response. Known issues included delayed recovery after lowering the board, free hip joints, resting bias, and vibration-driven twitching.
